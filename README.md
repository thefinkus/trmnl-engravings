# trmnl-engravings

Static image hosting (GitHub Pages) for the TRMNL plugin **Engraving of the Day**: copper
engravings, etchings and woodcuts, each as three native 1872×1404 16-grey PNGs
(`s{metid}_full.png` whole sheet, `_fill.png` cover crop, `_det.png` close-up).

Images: [The Metropolitan Museum of Art](https://www.metmuseum.org), Open Access,
[CC0](https://creativecommons.org/publicdomain/zero/1.0/). All works are in the public domain.
No endorsement by the Museum is implied. `manifest.json` lists artist, title, date and Met object id.
